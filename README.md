# BANKPROJECT
## Описание:
Bankproject - мой учебный проект, где я делаю виджет для банка

## Установка:
1. Клонируйте репозиторий
```
git clone https://github.com/LexaNovikov/bankproject.git
```

2. Установите poetry
```
pip install poetry
```
 
3. Инициализируйте poetry
```
poetry init
```

4. Установите зависимости
```
poetry install
```
5. Создайте файл .env по образцу .venv.example и замените данные на свои
```
API_KEY=UourApiKey
```
## Использование:
Запустите src.main из корневой папки

```
cd Папка/проекта
```

```
python -m src.main
``` 

## Документация:
### В пакете ```src``` лежат модули кода:
```main.py```
Главный файл для работы проекта, объединяет все модули во едино

```masks.py```
Содержит функции маскировки карты и счета

```widget.py```
Содержит функцию распознавания карты и счета и в дальнейшем маскирует их

```processing.py``` 
Содержит функции фильтров по дате и статусу

```generators.py```
Содержит функции генерации номера карты, фильтрации транзакций по валютам и вывод информации по транзакции 

```decorators.py```
Сожержит декоратор log для логирования ошибок или успешной работы функции

```external_api.py```
Содержит функцию возврата стоимости транзакции в рублях

```utils.py```
Содержит функцию получения списка операций

```read_sheets.py```
Содержит функции чтения csv и xlsx файлов

```filters.py```
Содержит функции фильтрации по слову в описании и подсчета операций по описанию
